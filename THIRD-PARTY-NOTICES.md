# Third-party software in groovyscope

The wheel bundles the engine JAR, which contains the libraries below. Each keeps its own licence; the texts are at
the addresses given, and the notices of the Apache-licensed ones are merged into the JAR's `META-INF/NOTICE`.
`groovyscope` itself is under the Apache License 2.0 (`LICENSE`).

| Component | Licence |
|---|---|
| Apache Groovy and its modules (with the ANTLR 4 runtime, ASM and picocli it embeds) | Apache-2.0; ANTLR and ASM: BSD-3-Clause |
| CodeNarc | Apache-2.0 |
| Apache Ant | Apache-2.0 |
| Google Guava, failureaccess, listenablefuture, Error Prone annotations, J2ObjC annotations | Apache-2.0 |
| Gson | Apache-2.0 |
| SQLite JDBC (Xerial), with SQLite | Apache-2.0; SQLite: public domain |
| GeAnTyRef, JSpecify | Apache-2.0 |
| JavaParser | Apache-2.0 (dual licensed with LGPL-3.0-or-later; distributed here under Apache-2.0) |
| Eclipse LSP4J | EPL-2.0 |
| Eclipse Layout Kernel (ELK) | EPL-2.0 |
| Eclipse Xtext Xbase runtime library | EPL-2.0 |
| Eclipse Modeling Framework (common, Ecore, Ecore XMI) | EPL-1.0 |
| JUnit 4 (used by CodeNarc's JUnit rules) | EPL-1.0 |
| Hamcrest | BSD-3-Clause |
| commonmark-java | BSD-2-Clause |
| SLF4J API | MIT |
